# Эвакуатор 24

Готовый статический сайт без сборки и платных сервисов. Откройте `index.html` в браузере или опубликуйте папку на GitHub Pages, Netlify или Cloudflare Pages.

## Настройка

Все публичные тексты, реклама, номера, ссылки на мессенджеры и тарифы находятся в `config.js`. Укажите реальные `telegramUsername` и `whatsappNumber` до публикации. Кнопки заявки откроют соответствующий мессенджер с уже заполненным сообщением.

Стоимость считается так: базовая подача + (километры × тариф) + доплата за тип машины + доплата за состояние. Ночной коэффициент применяется ко всей сумме.
